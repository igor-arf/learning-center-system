# Система управления учебным центром

Комплексная веб-платформа для управления учебным центром английского языка с уникальной системой ротации преподавателей и автоматическим планированием расписания.

## 🎯 Ключевые особенности

### Уникальная система ротации
- **Автоматическая ротация после каждых 6 занятий**: Система автоматически назначает Екатерину (руководителя) на контрольные занятия и расширенную лексику
- **Компенсационная работа**: Основные преподаватели получают альтернативные задачи с гарантированной оплатой
- **Сохранение стабильного дохода**: Все преподаватели получают постоянную зарплату независимо от ротации

### Умное планирование расписания
- **Автоматическая генерация** с учетом всех ограничений
- **Обнаружение и разрешение конфликтов** в реальном времени
- **Оптимизация пикового времени** (13:00-17:00)
- **Балансировка нагрузки** между преподавателями

### Специфика бизнеса
- **Два филиала** с разными возможностями (Бульвар: 3 кабинета, Улитка: 1 кабинет)
- **Уникальные ограничения преподавателей** по филиалам и нагрузке
- **Специальные паттерны расписания**: Вт+Чт, Ср+Сб, Пн+Пт
- **Детальная аналитика** и финансовые расчеты

- **ScheduleConflict** (Конфликт расписания) - автообнаружение и решения

## 🔧 Ключевые алгоритмы

### 1. Генератор расписания (`ScheduleGenerator`)

Умный алгоритм, который:
- Анализирует доступность ресурсов (кабинеты, преподаватели)
- Планирует обычные занятия с учетом паттернов групп
- Резервирует время для специальных занятий Екатерины
- Распределяет компенсационную работу
- Оптимизирует использование пикового времени
- Автоматически обнаруживает и предлагает решения конфликтов

```python
# Основная функция генерации
def generate_schedule(self, branch_id: int, week_start: datetime) -> Dict:
    # 1. Анализ доступности ресурсов
    available_slots = self._analyze_resource_availability(branch, week_start)
    
    # 2. Планирование обычных занятий
    regular_lessons = self._schedule_regular_lessons(active_groups, available_slots, week_start)
    
    # 3. Планирование специальных занятий
    special_lessons = self._schedule_special_lessons(active_groups, available_slots, week_start)
    
    # 4. Распределение компенсационной работы
    compensation_work = self._distribute_compensation_work(active_groups, available_slots, week_start)
    
    # 5. Обнаружение и разрешение конфликтов
    conflicts = self._detect_and_resolve_conflicts(regular_lessons + special_lessons)
    
    # 6. Оптимизация пикового времени
    optimized_schedule = self._optimize_peak_time_usage(regular_lessons + special_lessons, branch)
```

### 2. Менеджер ротации (`RotationManager`)

Автоматизирует процесс завершения юнитов:

```python
def plan_unit_completion(self, unit_id: int) -> Dict:
    # 1. Назначить Екатерину на контрольное занятие
    control_lesson = self._schedule_special_lesson(unit, ekaterina, 'control')
    
    # 2. Назначить Екатерину на лексическое занятие
    vocab_lesson = self._schedule_special_lesson(unit, ekaterina, 'vocabulary')
    
    # 3. Найти компенсационную работу основному преподавателю
    compensation_work = self.distribute_compensation_work(main_teacher.id, free_slots)
    
    # 4. Обеспечить сохранение зарплаты
    guaranteed_income = self._calculate_guaranteed_income(main_teacher, unit)
```

### 3. Анализатор конфликтов (`ConflictResolver`)

Обнаруживает и предлагает решения для:
- Двойного бронирования кабинетов
- Конфликтов преподавателей
- Превышения дневной нагрузки
- Нарушений паттернов групп
- Недоступности филиалов

## 💼 Бизнес-логика

### Система ротации преподавателей

**Проблема**: После каждых 6 занятий группе нужны контрольные работы и расширенная лексика, которые ведет только руководитель (Екатерина).

**Решение**:
1. **Автоматическое отслеживание**: Система следит за прогрессом каждой группы
2. **Планирование спецзанятий**: Автоматически назначает Екатерину на контрольные и лексические занятия
3. **Компенсационная работа**: Основной преподаватель получает альтернативные задачи:
   - Замещение коллег
   - Индивидуальные занятия
   - Разговорные клубы
   - Проверка домашних заданий
   - Административная работа
4. **Гарантированный доход**: Все преподаватели получают стабильную оплату

### Ограничения преподавателей

#### Диана
- Только филиал "Бульвар"
- Нормальная загрузка (6 занятий/день макс.)
- Дни: Вторник + Четверг

#### Эмилия (Администратор)
- Оба филиала
- Ограниченная загрузка (3-4 занятия/день)
- Административные обязанности

#### Ирина Ивановна
- Только филиал "Бульвар"
- Минимальная загрузка (предпенсионный возраст)

#### Екатерина (Руководитель)
- Оба филиала
- Ведет только специальные занятия (контрольные + лексика)
- Административная работа

## 🆘 Поддержка

### Частые проблемы

**Проблема**: Конфликты в расписании не разрешаются автоматически
**Решение**: Проверьте доступность альтернативных временных слотов и кабинетов

**Проблема**: Преподаватель не может быть назначен на занятие
**Решение**: Убедитесь, что преподаватель имеет доступ к филиалу и не превышена дневная нагрузка

**Проблема**: Ротация не срабатывает после завершения юнита
**Решение**: Проверьте, что в системе есть преподаватель с правами на специальные занятия
